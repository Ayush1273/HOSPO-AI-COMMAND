# HOSP-AI COMMAND

## AI-Powered Hospital Operational Decision Support Prototype

HOSP-AI COMMAND is an AI-based hospital operational decision-support
prototype designed to help administrators monitor hospital conditions,
forecast ICU occupancy, assess operational risk, and receive
policy-grounded recommendations.

The system combines Machine Learning, a deterministic operational
risk engine, Retrieval-Augmented Generation (RAG), and a Large
Language Model (LLM).

---

## System Architecture

Hospital Operational Inputs
        ↓
Feature Engineering
        ↓
XGBoost Machine Learning Model
        ↓
24-Hour ICU Occupancy Forecast
        ↓
Deterministic Operational Risk Engine
        ↓
Risk Score + Risk Level + Risk Factors
        ↓
RAG Policy Retrieval
        ↓
Gemini LLM
        ↓
Policy-Grounded Operational Recommendations
        ↓
Streamlit Dashboard

## Machine Learning Model

The system uses a trained XGBoost regression model to predict
ICU occupancy for the next 24 hours.

Model file:

models/xgb_model.json

The model uses 39 operational and engineered features, including:

- ER arrivals
- Ambulance arrivals
- ICU admissions
- ICU discharges
- ICU transfers
- ICU occupied beds
- ICU available beds
- ICU occupancy
- Hospital occupancy
- Ventilator availability
- ICU staff availability
- Staffing shortage flag
- Elective surgeries
- Time-based features
- ICU occupancy lag features
- ICU admission lag features
- Rolling occupancy features
- Rolling emergency-arrival features

---

## Risk Assessment

The numerical operational risk score is generated by a deterministic
risk engine.

The risk engine considers factors such as:

- Current ICU occupancy
- Predicted ICU occupancy trend
- ICU bed availability
- Staffing shortage
- Ventilator availability
- ICU patient flow
- Emergency department inflow

The risk engine produces:

- Risk Score
- Risk Level
- Risk Components
- Key Risk Factors
- Positive Forecast Trends

The LLM does not calculate or modify the numerical risk score.

---

## Retrieval-Augmented Generation (RAG)

The system uses a hospital operational knowledge base containing
synthetic hospital policies.

The RAG component retrieves relevant policies based on the current
hospital operational situation.

RAG files:

hosp_ai_embeddings/
├── document_embeddings.npy
└── embedded_knowledge_base.csv

Retrieved policies are provided to the LLM as supporting context
for generating operational recommendations.

---

## AI Decision Support

The Gemini LLM acts as the explanation and recommendation layer.

It receives:

1. Current hospital operational conditions
2. Machine learning forecast
3. Deterministic operational risk assessment
4. Retrieved hospital policies

The LLM generates:

- Operational situation summary
- Forecast interpretation
- Key risk factors
- Policy-supported recommendations
- Supporting policies
- Limitations and human-review requirements

The LLM is not used for clinical diagnosis, treatment,
patient-specific medical advice, or autonomous clinical decisions.

## Installation

### 1. Create a virtual environment

Windows:

    python -m venv .venv

Activate it:

    .venv\Scripts\activate

### 2. Install dependencies

    pip install -r requirements.txt

---

## Running the Application

Run the Streamlit dashboard using:

    streamlit run app.py

The application will open in the browser.

The default local Streamlit address is usually:

    http://localhost:8501

Streamlit officially recommends `streamlit run app.py` for launching
a local application. 

---

## Gemini API Configuration

The Gemini API key should NOT be hard-coded inside app.py.

Set the API key as an environment variable or use Streamlit secrets.

Example environment variable:

    GEMINI_API_KEY=YOUR_API_KEY

Never commit an API key to GitHub or expose it publicly.

## Important Limitations

HOSP-AI COMMAND is an academic research and prototype system.

The operational data and policy thresholds used in the prototype
are synthetic and should not be interpreted as validated hospital
clinical guidelines.

The system does not provide:

- Patient diagnosis
- Patient treatment recommendations
- Clinical triage
- Medication recommendations
- Autonomous clinical decisions

All recommendations require human review by appropriate hospital
administrators and operational personnel.
